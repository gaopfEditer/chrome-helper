# 加密社交回复助手 Chrome 扩展

一个智能的 Chrome 扩展，帮助用户自动回复币安广场、OKX 和 Gate 平台的社交帖子。支持 LLM 生成回复、批量审核、智能队列管理和反封禁策略。

## ✨ 功能特性

### 核心功能
- 🎯 **多平台支持**：币安广场、OKX 社区、Gate 广场
- 👥 **目标用户管理**：维护目标用户列表，支持导入/导出 JSON
- 🔄 **自动获取帖子**：从目标用户资料页自动获取最新帖子
- 🤖 **LLM 智能生成**：通过 OpenAI 兼容 API 生成个性化回复
- 📝 **回复模板系统**：支持自定义模板作为备选方案
- ✅ **完整审核流程**：可视化审核界面，编辑、重新生成、批准或跳过
- 🚀 **批量发送队列**：智能队列管理，支持暂停、恢复和停止

### 反封禁策略
- ⏱️ **随机延迟**：可配置的随机延迟（默认 60-180 秒）+ 抖动
- 🛑 **速率限制**：每小时、每日、每用户每日回复上限
- 🕐 **活跃时段**：可设置仅在指定时间段内运行
- 👆 **人性化交互**：模拟打字速度、随机滚动、真实点击
- 🔍 **智能检测**：自动检测验证码、限流、登录墙并停止队列
- 🎲 **回复差异检测**：确保批量回复不会过于相似

### 技术架构
- 🏗️ **平台适配器层**：独立的适配器处理各平台的 DOM 交互
- ⚙️ **可配置选择器**：CSS 选择器集中配置，方便更新
- 📊 **调试模式**：详细日志记录选择器匹配情况
- 💾 **持久化存储**：使用 chrome.storage.local 保存所有数据
- ⏰ **chrome.alarms**：使用 Alarms API 确保长时间队列稳定运行

## 🚀 安装说明

### 前置要求
- Node.js 16+ 和 npm
- Chrome 浏览器（Manifest V3 支持）

### 安装步骤

1. **克隆或下载项目**
```bash
git clone <repository-url>
cd crypto-social-reply-assistant
```

2. **安装依赖**
```bash
npm install
```

3. **构建扩展**
```bash
npm run build
```

构建完成后，`dist` 目录将包含可加载的扩展文件。

4. **准备图标** （重要）

扩展需要以下图标文件（当前为占位符）：
- `public/icons/icon16.png` (16x16)
- `public/icons/icon48.png` (48x48)
- `public/icons/icon128.png` (128x128)

推荐使用渐变紫色主题（#667eea → #764ba2）配白色图标。

5. **加载到 Chrome**

   a. 打开 Chrome 浏览器，访问 `chrome://extensions`
   
   b. 开启右上角的 **开发者模式**
   
   c. 点击 **加载已解压的扩展程序**
   
   d. 选择项目的 `dist` 目录
   
   e. 扩展将出现在扩展列表中

## 📖 使用指南

### 首次配置

1. **打开设置页面**
   - 点击扩展图标 → **⚙️ 设置**
   - 或右键扩展图标 → **选项**

2. **配置 LLM（可选）**
   - 切换到 **LLM 配置** 标签
   - 勾选 **启用 LLM 生成回复**
   - 填入 OpenAI 兼容 API 信息：
     - Base URL（如 `https://api.openai.com/v1`）
     - API Key
     - 模型名称（如 `gpt-3.5-turbo`）
   - 调整系统提示词、温度、Token 数等参数

3. **配置反封禁策略**
   - 切换到 **反封禁设置** 标签
   - 设置延迟范围（推荐保守值：60-180 秒）
   - 设置每小时/每日上限（推荐：10/小时，50/天）
   - 设置活跃时段（如 09:00-23:00）
   - 勾选 **检查回复内容差异**

4. **添加目标用户**
   - 切换到 **目标用户** 标签
   - 点击 **➕ 添加目标用户**
   - 输入平台（binance/okx/gate）
   - 输入用户名和资料页 URL
   - 设置每个用户获取的帖子数和时间范围

5. **保存设置**
   - 点击页面底部的 **💾 保存设置**

### 工作流程

#### 1. 获取帖子

打开 **审核页面**（扩展图标 → 📋 审核回复）：
- 点击 **🔄 获取帖子**
- 扩展将在后台标签中访问每个目标用户的资料页
- 自动抓取最新帖子（跳过已回复的帖子）

**手动添加帖子**：也可以直接输入帖子 URL 点击 **添加**。

#### 2. 生成回复

- 点击 **✨ 生成回复**
- 如果启用了 LLM，将调用 API 生成个性化回复
- 否则使用预设的回复模板（可在设置中配置）

#### 3. 审核回复

每条帖子显示为卡片，包含：
- 原帖内容、作者、时间
- 生成的回复（可编辑）
- 操作按钮：
  - ✏️ 编辑：手动修改回复内容
  - 🔄 重新生成：用 LLM 重新生成回复
  - ✅ 批准：标记为已批准，加入发送队列
  - ⏭️ 跳过：跳过这条帖子

**批量操作**：
- **✅ 批量批准**：批准所有待审核的回复
- **⏭️ 批量跳过**：跳过所有待审核的回复

#### 4. 发送回复

- 确认已批准需要发送的回复
- 点击 **🚀 开始发送**
- 队列开始运行：
  - 检查速率限制和活跃时段
  - 按顺序发送每条回复（随机延迟）
  - 在真实页面中模拟人工操作
  - 自动检测封禁/验证码并暂停

**队列控制**（弹出窗口或审核页面）：
- **▶️ 开始**：启动队列
- **⏸️ 暂停**：暂停队列（可恢复）
- **⏹️ 停止**：完全停止队列

## 🔧 平台选择器配置

如果目标网站更新了 HTML 结构导致无法获取帖子或发送回复，可以更新选择器：

1. 打开 **设置** → **平台选择器** 标签
2. 选择需要更新的平台（币安/OKX/Gate）
3. 勾选 **调试模式** 以查看选择器日志
4. 更新相应的 CSS 选择器（每行一个，优先级从上到下）
5. 保存设置

**关键选择器**：
- `postsContainer`：帖子列表容器
- `postItem`：单条帖子元素
- `postContent`：帖子内容
- `replyButton`：回复按钮
- `replyInput`：回复输入框
- `submitButton`：提交按钮
- `captcha`、`rateLimit`、`loginWall`：封禁检测

   - 币安广场的 DOM 选择器准确性

2. **帖子获取流程**
   - 用户资料页导航

3. **回复发送流程**
   - 打开帖子详情页

   - 提交回复
   - 验证回复成功

4. **封禁检测**
   - 验证码识别
   - 限流提示检测
   - 登录墙检测
   - 异常响应处理

### 调试建议

1. **开启调试模式**
   - 设置 → 平台选择器 → 勾选"调试模式"
   - 打开 Chrome DevTools 查看控制台日志

2. **逐步测试**
   - 先测试"手动添加帖子 URL"
   - 在审核页面编辑回复内容
   - 测试队列启动但不实际发送（注释发送代码）

3. **更新选择器**
   - 访问目标平台，使用 DevTools 检查元素
   - 更新 `src/adapters/index.ts` 中的 `DEFAULT_PLATFORM_SELECTORS`

4. **测试封禁检测**
   - 故意降低延迟触发限流
   - 验证扩展是否正确暂停并提示用户

## 🔒 安全说明

- **绝不存储密码**：扩展使用您已登录的浏览器会话，不请求或保存站点密码
- **API Key 安全**：LLM API Key 仅存储在本地 chrome.storage.local，不上传到任何服务器
- **数据隐私**：所有数据（目标用户、帖子、回复历史）仅保存在本地浏览器
- **权限最小化**：仅请求必要的 Chrome 权限（storage、alarms、tabs、scripting）
